# Detailed Role Matching Criteria

## Quick Role-to-Skills Reference

| Target Role | Key Skills to Match |
|-------------|---------------------|
| **ML/AI Engineer** | PyTorch, TensorFlow, LLM fine-tuning (QLoRA), RAG, LangChain, CrewAI |
| **Backend/SDE** | Python, Go, FastAPI, REST APIs, microservices |
| **DevOps/Platform** | Kubernetes, AWS, Docker, Terraform, CI/CD |
| **MLOps Engineer** | SageMaker, model deployment, pipelines, monitoring |
| **Full Stack** | React, Node.js, Python, databases |
| **Cloud Engineer** | AWS (Lambda, EKS, SageMaker), IaC |

## Experience Level Guidelines

| JD Requirement | Fit Assessment |
|----------------|----------------|
| Entry/Junior (0-2 years) | TOP PICK |
| Mid-level (2-5 years) | TOP PICK / HIGH |
| Senior (5-7 years) | STRETCH |
| Staff/Principal (7+ years) | SKIP |
| "X+ years" where X > 5 | SKIP unless other factors strong |

## Red Flags (Auto-SKIP)

Do not include jobs with ANY of these:
- Security clearance required (TS, Secret, etc.)
- US Citizenship required
- "Must be authorized without sponsorship"
- Specific tools: Splunk, ServiceNow, Workday, Salesforce admin, SAP
- iOS/Swift as primary requirement
- 10+ years experience required
- Director/VP/C-level titles

## Green Flags (Boost Score)

Increase match score for:
- "New grad friendly" or "early career"
- Visa sponsorship mentioned positively
- Remote-first or flexible location
- Startup/growth stage companies (more flexible on experience)
- Technologies: Python, PyTorch, LLMs, AWS, Kubernetes, Go

## Location Filtering

Include ONLY:
- "Remote" / "Remote - US" / "Remote, United States"
- US cities/states (New York, California, Texas, Washington, Michigan, etc.)
- Hybrid US locations

Exclude:
- Non-US locations (London, Berlin, Singapore, etc.)
- "Remote - EMEA", "Remote - APAC"
- Locations without country specified (ambiguous)

## Output Guidelines

Sort CSV by:
1. Fit Category (TOP PICK first, then HIGH, then STRETCH)
2. Within category, by Match Score (highest first)

Provide reasoning in "Key Matches" and "Gaps" columns:
- Key Matches: List 2-4 skills/requirements that align
- Gaps: List any concerns (experience level, missing skills)
